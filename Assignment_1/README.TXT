# Assignment 1

This project compares two different classifiers on an imbalanced dataset to compare how they perform by precision, recall and Macro-F1. This was done as a part of our first assignment in our Machine Learning (DV2638) course at BTH.

### Steps

1. Open `assignment1.ipynb` and select the Python kernel you want to use.
2. Run the setup cell at the start of the notebook to install the packages, if needed.
3. Run the remaining code cells to reproduce the analysis and results.
