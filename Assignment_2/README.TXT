# Assignment 2

This project compares three different supervised classification models via fit time, F-score and accuracy score by using techniques such as Friedman test and Nemenyi test to show if theres any statistics significanse between the models. This was done as a part of our second assignment in our Machine Learning (DV2638) course at BTH.

### Steps

1. Open `assignment2.ipynb` and select the Python kernel you want to use.
2. Run the setup cell at the start of the notebook to install the packages, if needed.
3. Run the remaining code cells to reproduce the analysis and results.
